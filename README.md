# 風起淡水 · 四年練習曲

一個原創、繁體中文、可完整遊玩四年的 HTML5 校園生活養成遊戲。

**遊玩：** https://zuestrd20.github.io/tamkang-four-years/

主角姜彥廷是 18 歲以上的虛構成年學生。故事以「淡江大學資工系四年生活」為題材，但校園景觀、課程、財務、學期制度、實習與劇情均為架空遊戲化設定，不代表校方現行資訊。非淡江大學官方產品。其他角色皆為成年虛構人物，與同名真人無關。

## 怎麼玩

- 共 48 個月、8 個學期。每月安排 3 個活動，依選擇順序執行。
- 點選一個日程時段，再選讀書、程式、作品、社團、小聚、打工、運動、休息；大三起可實習。
- 管理學業、程式、社交、體能、健康、壓力及預算。高壓與低健康影響學習收益；休息與運動可恢復。
- 每月遊戲設定提供 3,000 支持、收取 2,800 生活費，短缺會由緊急協助補足並增加壓力；低健康有安全恢復。沒有資源耗盡造成的永久卡關。
- 隨機事件採種子洗牌牌庫，抽完一輪前不重複。每學期有一次無限時程式小挑戰；答錯也有經驗收益。
- 持續製作專題累積里程碑。七種畢業路線按公開條件與優先序判定，可在遊戲中查看。
- 自動存檔每月更新；手動存檔獨立保留。讀檔可選任一種。重開有確認，會保留手動檔。

## 操作與無障礙

桌面滑鼠、鍵盤 Tab／Enter、手機觸控皆可操作。無計時挑戰、不依靠顏色辨識數值。使用原生對話框與可見鍵盤焦點；動態尊重 reduced-motion。音樂預設關閉，須主動開啟，分頁隱藏時暫停。瀏覽器儲存遭封鎖時會顯示提示。

進度僅保存在使用者當前瀏覽器的 localStorage，沒有帳號、伺服器、追蹤器、遠端資料傳送或跨裝置同步。清除網站資料也會清除進度。

## 原創與參考界線

本作參考排程養成類遊戲的抽象機制；未使用《美少女夢工廠》的程式、素材、人物、情節、名稱或音樂。選用輕量專題進度、角色關係、選擇事件、無限時短挑戰及多結局。沒有宣稱任何玩法在特定期間的銷量、人氣或排名。

介面、角色設定、事件、程式與音樂為此作品撰寫。插畫由生成式影像工具依原創角色與架空場景設計生成。音樂由 Web Audio 即時合成原創 16 音短循環，沒有引用音檔或商業旋律。詳細資產說明見 assets/ART_NOTES.md；機制參考見 SOURCES.md。

## 本機開發

使用 Node.js 20+：

```sh
npm install
npm test
python3 -m http.server 8080
```

在瀏覽器開啟本機伺服器。不要直接以 file:// 開啟，因為原生 ES modules 需要 HTTP。

無打包步驟、無執行時第三方套件。GitHub Pages 從 main 分支根目錄發布，`.nojekyll` 避免 Jekyll 轉換。

## 檔案

- `engine.js`：純函式、種子隨機、資源結算、事件、存檔驗證與結局
- `app.js`、`index.html`、`style.css`：使用者介面與本機儲存／音訊
- `assets/`：原創插畫
- `engine.test.mjs`、`ui.test.mjs`：引擎與 DOM 流程回歸測試
- `QA.md`：驗證範圍與限制
